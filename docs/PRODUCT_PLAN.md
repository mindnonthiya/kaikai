# แผนผลิตภัณฑ์ kaikai

## เป้าหมายและผู้ใช้

kaikai เป็นเว็บสำหรับเจ้าของร้านข้าวไก่ต้มน้ำปลา ใช้บันทึกยอดขาย ต้นทุน และค่าใช้จ่ายจากมือถือ โดยทำให้คำตอบของคำถาม “วันนี้ขายเท่าไร เหลือกำไรเท่าไร” มองเห็นได้ทันที

## โครงสร้างหน้าจอ

1. **ภาพรวม** — ตัวเลขหลัก, กราฟ 7 วัน, เมนูเด่น, รายการล่าสุด และคำเตือน
2. **เพิ่มรายการขาย** — เลือกเมนูและจำนวนด้วยมือเดียว เห็นยอดรับ ต้นทุน และกำไรแบบสด
3. **ประวัติการขาย** — ค้นหา ดูสถานะ และตรวจยอดชำระ
4. **เมนูและสูตรต้นทุน** — ราคาขาย สูตร ต้นทุนต่อกล่อง และ margin
5. **วัตถุดิบ** — ราคาซื้อ ปริมาณใช้ได้จริง และต้นทุนเฉลี่ยถ่วงน้ำหนัก
6. **ค่าใช้จ่าย** — แยก direct cost, operating, one-time และ recurring
7. **รายงาน** — สรุปช่วงเวลาและ CSV
8. **ตั้งค่า** — ร้าน บัญชี และสถานะการเชื่อมต่อ

Desktop ใช้ sidebar ส่วน mobile ใช้ bottom navigation และปุ่ม “เพิ่มยอดขาย” ที่เข้าถึงง่าย

## แบบจำลองข้อมูล

`auth.users` เป็นบัญชีหลัก และ `profiles` เก็บข้อมูลแสดงผล ตารางธุรกิจทุกตารางมี `owner_id` และ RLS จำกัดด้วย `auth.uid()` ความสัมพันธ์สำคัญคือ:

- ingredient → ingredient_purchases
- menu → menu_recipe_items → ingredient/packaging
- sale → sale_items, payments, slip_uploads
- sale_item เก็บ cost snapshot ไม่อ้างต้นทุนปัจจุบันในการทำรายงานย้อนหลัง
- audit_logs เก็บเหตุการณ์แก้ไข/ยกเลิกที่สำคัญ

## สูตร (เก็บเงินเป็น integer หน่วยสตางค์)

- ต้นทุนวัตถุดิบต่อหน่วย = ราคาซื้อ ÷ ปริมาณใช้ได้จริง
- ต้นทุนเมนู = วัตถุดิบ + บรรจุภัณฑ์ + ค่าแรง + ค่าใช้จ่ายแฝง
- รายได้สินค้า = ราคาขาย × จำนวน
- รายได้สุทธิ = รายได้สินค้า − ส่วนลด + ค่าส่งที่เรียกเก็บ − ค่าธรรมเนียม
- COGS = ต้นทุน snapshot ต่อหน่วย × จำนวน
- กำไรขั้นต้น = รายได้สุทธิ − COGS
- กำไรสุทธิ = กำไรขั้นต้น − ค่าใช้จ่ายดำเนินงาน
- กำไรเฉลี่ย/กล่อง = กำไรขั้นต้น ÷ จำนวนกล่อง
- margin = กำไรขั้นต้น ÷ รายได้สุทธิ × 100

ทุกสูตรป้องกันการหารศูนย์ จำนวนติดลบ และหลีกเลี่ยง JavaScript floating point สำหรับเงินจริง

## ขอบเขต MVP

ทำ: Auth, route protection, RLS, dashboard, บันทึกการขายแบบ atomic, cost snapshots, วัตถุดิบ/เมนู/ค่าใช้จ่าย, private slip storage, manual slip entry, duplicate metadata, CSV, seed, unit/E2E foundation และเอกสาร deploy

ยังไม่เปิดใช้: OCR provider จริง, inventory depletion, accounting/tax integration, multi-staff roles และ automatic bank verification
